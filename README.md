# CSS Layout & Accessibility Assignment

Three linked HTML pages with one shared stylesheet and five original local SVG illustrations.

## Assignment requirements included
- Three individual HTML pages, each with at least one image
- Five images on the Neighborhood and Parks pages
- HTML5 semantic structure and descriptive image alt text
- Skip-to-main-content link that appears on keyboard focus
- Navigation styled with flexbox and multiple CSS properties
- Box-model styling on images (width, border, padding, border-radius)
- CSS Grid with at least two columns
- Flexbox parent element for navigation
- Hover effects and transitions
- `figure:nth-child(2n) img` changes the border radius of alternating images
- Responsive layouts for smaller screens

## Publish on GitHub Pages
1. Extract the ZIP file.
2. Upload the three HTML files, `README.md`, and both folders (`css` and `images`) into the root of your repository.
3. Keep the folder structure exactly as provided.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. Wait for the Pages URL to appear and open it to test all three pages.

## Validation
- HTML: https://validator.w3.org/
- Accessibility: https://wave.webaim.org/

Paste each published page URL into the validators and review any reported issues.
